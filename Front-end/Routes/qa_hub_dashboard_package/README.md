# Q&A Hub Teacher Dashboard

## Files
- `index.html` — dashboard markup and lightweight interactions.
- `css/style.css` — visual styling and responsive layout.

## Run
Keep the `css` folder beside `index.html`, then open `index.html` in a modern browser. An internet connection may be needed for the externally hosted Plus Jakarta Sans font.

## Notes
The breadcrumb appears to the left of the search bar on desktop/tablet and updates when a sidebar section is selected. The Dashboard breadcrumb returns to the dashboard. Existing demo-only sections and profile actions remain placeholders and are not connected to a backend.
